# 🏃 PaceRunner

**Your Personal Running & Fitness Coach**

PaceRunner is an Android fitness application designed to make running more structured and effective through interval training, real-time GPS speed tracking, and personalized running goals.

## ✨ Features

- **10-Minute Interval Training:** Alternates between fast running and slow recovery intervals.
- **Live GPS Speed Tracking:** Monitors running speed in real time.
- **Voice Coach:** Provides audio instructions, speed updates, and interval transition alerts.
- **Personalized Weight Loss Plan:** Calculates running targets using height, current weight, and target weight.
- **Dynamic Speed Guidance:** Displays required fast and slow running speeds.
- **Workout Statistics:** Tracks distance, average speed, peak speed, and calories.
- **Workout History:** Saves completed workouts locally.
- **Indoor Simulation Mode:** Allows testing without GPS.
- **Haptic Feedback:** Provides vibration alerts during interval changes.

## 🛠️ Tech Stack

- Kotlin
- Android SDK
- Jetpack Compose
- Room Database
- GPS / Location Services
- Android Text-to-Speech (TTS)
- MVVM Architecture
- Kotlin Coroutines

## 📱 How It Works

1. Enter your height, current weight, and target weight.
2. Generate your personalized running plan.
3. Start your 10-minute workout.
4. Follow alternating fast and slow running intervals.
5. Monitor your live speed and listen to voice coaching.
6. Review your workout statistics and history.

## 🎯 Project Objective

To build a smart running companion that combines Android development, GPS technology, voice interaction, and personalized fitness tracking into one application.

## ⚠️ Disclaimer

Running speeds and weight-loss estimates are guidance, not medically validated prescriptions or guaranteed outcomes. Adjust workout intensity to your fitness level and consult a qualified professional if needed.
